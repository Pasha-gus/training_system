# Обучающая система

## Описание:
LMS-система, в которой каждый желающий может размещать свои полезные материалы или курсы.

## Установка: 
1. Клонируйте репозиторий https://github.com/Pasha-gus/training_system
2. Создайте и активируйте виртуальное окружение: python -m venv venv
3. Установите зависимости pip install --no-cache-dir -r requirements.txt
4. Запустите сервер разработки python manage.py runserver

## Запуск проекта с использованием Docker Compose
### Требования
Установлен Docker Compose

### Подготовка окружения
1. Скопируйте файл .env.example в .env и заполните значениями.
2. Убедитесь, что файлы Docker (Dockerfile) и настройки приложений настроены правильно.

### Сборка и запуск проекта
Выполните команду в терминале: docker-compose up --build

### Проверка работоспособности 
В терминале введите docker-compose logs
Чтобы посмотреть список всех контейнеров созданных Docker Compose, и их текущее состояние испльзуйте команду docker-compose ps

## Документация:
Документация находится по ссылке http://127.0.0.1:8000/redoc/ или http://127.0.0.1:8000/swagger/
