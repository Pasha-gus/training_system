# Обучающая система

## Описание:
LMS-система, в которой каждый желающий может размещать свои полезные материалы или курсы.

## Установка: 
Клонируйте репозиторий https://github.com/Pasha-gus/training_system

## Использование:
Вы можете размещать на платформе свои уроки и курсы, а так же подписываться на уроки других пользователей. Какие запросы использовать для размещения обновления и удаления уроков и курсов, а также другие возможности платформы описанны документации

## Документация:
Документация находится по ссылке http://127.0.0.1:8000/redoc/ или http://127.0.0.1:8000/swagger/

## Лицензия:
Проект распространяется под [лицензией MIT](LICENSE).

## Тестирование: 
Протестированно с помощью модуля DRF unitest. Тесты находятся в файле test.py приложений courses и users
